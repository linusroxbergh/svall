# Part B wave fix round 1 — findings (binding)

1. (Important) P2 reports a running agent as failed after a 60 s stall (destination.ts:529, 493-498, 564-572) — the most likely outcome of a mid-activation kill: typing→Enter takes ~100 ms, Enter→SessionStart takes seconds, so most in-flight slots die after Enter with their agent booting. On the retry such a pane "runs something" and is kept, and wakeSlot waits SESSION_START_MS (60 s) for a SessionStart that already went to the dead daemon; a SessionStart that reached the restarted daemon before the retried Activate is also dropped (sessionStarted drops it with no waiter and no error row). The row then says the session "did not report its SessionStart" while the agent runs, and retry does nothing (char.revive returns early when tmux is set). Fix: remember SessionStarts for carried slots that arrive with no waiter and let wakeSlot accept them; count a kept pane whose process is the agent's kind as up (handover/processes.ts ProcessTable classifies kinds). Test this branch.

2. (Minor, promoted — it can kill a running agent) destination.ts:483 lists windows once for the whole pool; with concurrency 4 and 60 s waits a later slot is judged on a listing minutes old, so a pane where the user has since pressed Enter can be killed while its agent runs. Judge each slot on a fresh look at its own pane right before deciding.

3. (Minor, promoted — fails open against the spec's "characters that fail to resume remain dormant with their transcript and a visible error"; adjacent pre-existing) the guard ends at any row, error rows included, so a resume that exits back to the shell (e.g. a bad session) loses `agent` to the poll ~6 s later while its window stays open — neither dormant nor linked to its transcript. A slot whose row is an error stays dormant with agent/revive (its window closed or marked dormant as the existing dormant path does).

4. (tests) Cover replaceUnstarted's untested branches: a plain shell that is kept (and whether it gets the "restarted" notice when the dead daemon died before typing it), a missing or dead window, a pane running the agent (item 1), and reach.ts:99-101's drop(was) race fix.
