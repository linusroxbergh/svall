# M3 panel — The Architect (20 findings; paths under the impl worktree)
A1 medium performance — packages/cli/src/controller/transfer.ts:311 — every rsync item line becomes a duplicate, synchronously persisted entity event (~50k events for a 25k-file first copy: scrubbed, appendFileSync'd to events.ndjson, kept in HelperServer.lines unbounded, written to every client, bridged by Swift with one evaluateJavaScript each). copy() puts per itemized file; put() (385-389) calls onProgress each time; entryEvent drops `items`. Fix: emit only on state change or ≤1/s per entry, never for item-only puts.
A2 medium performance — cli controller/handover.ts:482 — each session file is its own entry: two rsync runs over ssh per file (copy + checksum dry run) plus ~3 durable journal flushes per file (O(N²)); minutes of frozen window for 12 sessions on Tailscale. Fix: one entry per session copying its file list into sessionStage with --files-from, no --delete, verified as a set.
A3 medium architecture — apps/desktop/web/src/handover.ts:7 — helper↔app NDJSON types hand-copied in three places (web redeclares Outcome/Verdict/SafeAction/CharacterResult/EntityData/HandoverEvent; cli events.ts; protocol messages.ts:310 a third handover.entity without bytes/totalBytes); already drifted (web preflight lacks `names`). Fix: declare once in @archipelago/protocol, import from cli and web.
A4 medium architecture — cli controller/events.ts:59 — session rows use an undocumented `s<index>:<file>` id the web parses (web handover.ts:85 slices at ':'; label "session s0"); namesOf() has no sessions map, so C13 can't name them. Fix: key session rows by character (and term) or add sessions to `names`; document the row id in the contract.
A5 medium dead-code — cli controller/paths.ts:1 — a re-export barrel only paths.test.ts imports; archid resolvePortablePath (portable-path.ts:51) has no other caller. Fix: move the test to archid, delete the barrel, use locatePath(...).portable.
A6 medium simplification (known C11) — cli commands/fleet-recover.ts:408 — gatewayPort/daemonPort reimplement the adapters and open one SshMaster per call (~4 logins on a recovery, each a possible askpass prompt). Fix: C11 with a shared per-machine master cache.
A7 low dead-code — archid handover/rest.ts:300 — scrollback capture and RestedTerminal detail fields have no production caller (SourceDeps.rest picks only waitMs/settleMs/pollMs/callTimeoutMs). Fix: drop until used.
A8 low dead-code — cli controller/recovery.ts:38 — ControllerJournal entries/pending/error written (handover.ts:424/594/669) but never read. Fix: remove.
A9 low simplification — cli commands/fleet-recover.ts:298 — inline writeRoute try/catch duplicates route.ts rememberOwner. Fix: call rememberOwner.
A10 low performance — cli controller/handover.ts:747 — observe() asks source status, ownership and destination status serially (and twice per machine without journals); the app runs status at every launch. Fix: Promise.all and reuse.
A11 low simplification — cli commands/handover.ts:244 — runHandover pre-checks the owner, then preflight asks the gateway again (an extra ssh round trip, two messages for one rule). Fix: drop the pre-check.
A12 low architecture — cli controller/handover.ts:642 — letGo reads the abort guard's not_owner as "nothing to let go", so any not_owner (e.g. a journal of another transaction) is swallowed and claimed roots stay receiving. Fix: abort answers {} when this machine holds no journal of the tx and is not its source, as complete does.
A13 low simplification — archid handover/destination.ts:73 — realClock, ask/serial, x.y.z comparison (×3) and claude/codex adapter bodies duplicated. Fix: share.
A14 low architecture — cli commands/handover-view.ts:16 — blocker→choice mapping in three places (destination.ts:88 ARCHIVABLE, handover-view.ts, web handover.ts:245-250). Fix: one map in protocol.
A15 low performance — archid handover/manifest.ts:244 — summarize() re-digests the manifest buildManifest just digested. Fix: pass the digest.
A16 low dead-code — archid handover/service.ts:46 — optional source/destination deps and notReady "not implemented yet" scaffolding; AUTHORITY.complete 'journal' never checked. Fix: make required, delete notReady.
A17 low simplification — apps/desktop/mac/.../Handover.swift:78 — LineChild is a third NDJSON child wrapper beside ControllerProcess/HostProcess. Fix: build HostProcess on LineChild.
