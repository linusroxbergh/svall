svall GitHub

All you need to run your agents, on one map.

Svall is a Mac app that puts each agent on an island, so one look shows which are working, waiting on you or done.

$ git clone https://github.com/linusroxbergh/svall$ cd svall$ pnpm desktop:install

macOS 15.6 or newer. Private alpha, invite only for now. Full setup

What it does

  • At a glance: the map keeps track of every agent, so you don't have to.
  • Layered context: per repo, island and agent, kept current for you.
  • Persistence: quit or reboot, and sessions pick up where they left off.
  • Built-in browser: PRs, previews and docs beside the terminal.
  • Built-in editor: edit files and review the diff in place.
  • On your phone: every agent and terminal, over Tailscale.
