Svall GitHub

Your coding agents, on one map.

Svall puts each of your Claude Code, Codex and OpenCode agents on an island, so you have a clear overview of their work and easy access to relevant context & resources. Each one runs in a real terminal on Svall’s own tmux server.

Download for Mac 
$ curl -fsSL https://svall.dev/install.sh | sh

Works with the Claude Code CLI, the Codex CLI or OpenCode. Build from source

What it does

  • Clear overview: the map keeps track of every agent, so you don't have to
  • Layered context: per repo, island and agent, kept current for you
  • Persistence: quit or reboot. Each agent resumes when you re-open
  • Built-in browser: PRs, previews and docs beside the terminal
  • Built-in editor: edit files and review the diff in place
  • On your phone: every agent and terminal, over Tailscale

Terminal, browser and files beside every agent.

One prompt sets up a whole island.

Press ⌘G and ask mission control, or ask any agent. It makes the island and its characters with the svall CLI, and each one starts your own Claude Code, Codex or OpenCode.

How it works

  • Claude Code and Codex report to Svall through their own hooks and OpenCode through a plugin, so a card changes the moment its agent starts, asks or finishes.
  • Each agent runs in a real terminal on Svall’s own tmux server, apart from yours.
  • Quitting stops the agents. Opening a character again resumes its conversation with claude --resume, codex resume or opencode -s.
  • No account and no telemetry. Setup adds Svall’s hook to Claude Code and Codex and its plugin to OpenCode, and svall uninstall takes them out.
  • Setup, the svall CLI and every file Svall writes are covered in the README on GitHub.
